# Plan: Gemini-powered `/haiku` and `/fortune` endpoints

## Context
`hello_api` is a small FastAPI app (`main.py`, `/hello` and `/goodbye`) managed with Poetry and deployed to Cloud Run. We're adding two GET endpoints whose text is generated by Gemini on Vertex AI through the `google-genai` SDK. Auth uses Application Default Credentials (ADC) only. The prompts are fixed, so the endpoints take no user input. If a Gemini call fails, the endpoint returns a JSON error instead of crashing.

## Steps

0. **Project housekeeping (CLAUDE.md rules)**
   - Add a time-stamped entry with this prompt to `PROMPTS.md`.
   - Branch: we're on `hello_goodbye_api` (already merged in commit `c925de9`). Create a new branch `gemini_endpoints` from it.
   - Save this plan as `plans/02_gemini_haiku_fortune.md`.

1. **Dependency**: run `poetry add google-genai`, then
   `poetry export -f requirements.txt --output requirements.txt --without-hashes`. The export plugin is already installed. We don't need any other packages (no python-dotenv).

2. **`main.py` changes**
   - Settings come from env vars, read at module level:
     `GOOGLE_CLOUD_LOCATION` (default `"global"`), `GEMINI_MODEL` (default `"gemini-3.1-flash-lite"`), `GOOGLE_CLOUD_PROJECT` (required).
   - **Lazy client**: `get_client()` is wrapped in `functools.cache` and builds `genai.Client(vertexai=True, project=..., location=...)` on first use. If `GOOGLE_CLOUD_PROJECT` is missing, the Gemini endpoints return a 500 JSON error. The app still starts, and `/hello` and `/goodbye` keep working. No API key or key file is used anywhere: the SDK picks up ADC.
   - The fixed prompt strings are module constants (`HAIKU_PROMPT`, `FORTUNE_PROMPT`).
   - A shared helper `generate(prompt) -> str` calls `client.models.generate_content` with
     `types.GenerateContentConfig(max_output_tokens=100, thinking_config=ThinkingConfig(thinking_level="minimal"))`.
     Thinking is kept minimal because Gemini 3 thinking tokens count toward the 100-token budget and could leave the answer empty or cut off. During implementation, check that the model accepts this setting and fall back to `"low"` if it doesn't. The helper strips the result. If the text is empty (for example, blocked by safety filters), it raises an error.
   - Endpoints are sync `def`, like the existing ones (FastAPI runs them in a threadpool):
     - `GET /haiku` → `{"haiku": "..."}`
     - `GET /fortune` → `{"fortune": "..."}`
   - **Error handling** (returned as `JSONResponse({"error": "<clear message>"}, status_code=...)`):
     | Failure | Status |
     |---|---|
     | `GOOGLE_CLOUD_PROJECT` unset | 500 |
     | ADC missing/invalid (`google.auth.exceptions.DefaultCredentialsError` / `RefreshError`) | 500 |
     | `google.genai.errors.APIError` with code 429 (quota/rate limit) | 503 |
     | other `APIError` (4xx/5xx from Vertex) | 502 |
     | empty/blocked response | 502 |
   - Details of each failure are written to the server log with `logging`. Clients get a short message without internal details.

3. **README.md**: add `/haiku` and `/fortune` to the endpoint table and update the intro sentence. Add a "Gemini / Vertex AI setup" section covering:
   - the env var table with defaults
   - enabling the API: `gcloud services enable aiplatform.googleapis.com`
   - local ADC: `gcloud auth application-default login`, then `export GOOGLE_CLOUD_PROJECT=...`
   - Cloud Run: set env vars with `--set-env-vars`. The runtime service account needs `roles/aiplatform.user`. ADC uses this service account automatically, so no keys are needed.
   - curl examples and the error response format.
